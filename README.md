# Alfie's iPhone 17 — Interactive AU Story

A responsive, clickable fictional iPhone for Alphonse “Alfie” Benjamin Summers, a 16-year-old Canadian-American actor and Starlight Performing Arts High School sophomore in New York. Open `index.html` directly or publish with GitHub Pages; no build step or external dependencies are required.

## Reader interaction

Send Alfie a message in Messages, ask him a question, or reply to a post in the school blog or forum. He answers immediately with locally authored, intent-aware dialogue. Responses have topic variations for the Stellaris ring and celestial archivist, family, Charlotte, pets, food/allergies, anxiety, school, co-stars, production staff, fans, and antagonists. The tone aims for casual, grounded teen conversation rather than grand or overly polished monologues. Chat history and journal notes are stored in the browser's local storage; use Reset in Messages to start that conversation over.

**AI note:** Replies are selected from character-written dialogue in the page; no live AI model, server, or external API is connected. This keeps the static story private and easy to host while providing instant interactive responses. A true generative service would require a secure backend and server-side API key, never a key embedded in client-side HTML.

The phone includes Discord, a school blog, fictional anonymous forums, journal, calendar, photos, music, contacts, and settings. Edit `index.html` to tune Alfie's voice or add story details. The AU and all conversations are fictional.
