# Alphonse's Phone — iPhone 17 AU

A readable, clickable, interactive fictional iPhone experience for an original-character alternate-universe story. It runs as a static page with no build tools or external dependencies.

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages. It is designed to work on desktop and mobile screens.

## Explore

Tap the app icons to visit Messages, Discord, Calendar, Photos, Music, Notes, Starlight Student Blog, anonymous AfterHours Forum, Safari, Contacts, Clock, Phone, Mail, and Settings. The story is set in New York at the fictional public Starlight Performing Arts High School. Alphonse is Canadian-American, and Charlotte Sanders is his crush/girlfriend.

Most character dialogue, replies, blog content, and forum activity are fictional, locally generated story text. There is no live AI service or network connection. Messages and notes can be saved in the current browser using local storage. You can edit the story details in `index.html` to suit your AU.
