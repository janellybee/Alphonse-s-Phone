# Alphonse's Phone

A fictional interactive iPhone AU story for Alphonse “Alfie” Summers. Open `index.html` or use GitHub Pages.

The phone includes Messages, Discord, Starlight blog, forums, Ask Alfie, an integrated Borough Beacon newspaper, an AU Wiki app, and Spotlight, an interactive flipbook-style magazine. Character dialogue is locally authored; story beats rotate every five minutes. No live AI is used. PIN `2106` is fictional UI only.
